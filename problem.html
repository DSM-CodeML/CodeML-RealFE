Mean Squared Error

Easy
+10 XP AI Fundamentals · Chapter 2

Given two lists of numbers, y_true and y_pred, of equal length, return the mean squared error between them. MSE is the average of the squared differences between each true value and its prediction.

Example

Input
y_true = [1.0, 2.0, 3.0]
y_pred = [1.0, 2.0, 4.0]
Output
0.3333

Constraints

  • 1 ≤ n ≤ 10,000
  • Both lists have the same length
  • Every value is a float in [−1000, 1000]

Solution

The mean squared error penalizes large mistakes more than small ones, because every difference is squared before it is averaged. A single pass over both lists is enough.

Approach

  1. Pair each true value with its prediction using zip.
  2. Add up the squared differences.
  3. Divide the total by the number of items.

Reference code

def mse(y_true, y_pred):
    total = 0
    for a, b in zip(y_true, y_pred):
        total += (a - b) ** 2
    return total / len(y_true)

Complexity

Time O(n), space O(1). Each element is visited exactly once and only a running total is stored.

Basic concepts

What is a loss function?

A loss function turns “how wrong is the model?” into a single number. Training means changing the model’s parameters until that number gets as small as possible.

Mean squared error

MSE = (1 / n) × Σ (yᵢ − ŷᵢ)²
  • yᵢ is the true value and ŷᵢ is the model’s prediction
  • Squaring removes the sign, so over- and under-shooting both count
  • Large errors grow quickly, so outliers have a strong effect

When to use it

MSE is the default choice for regression problems such as predicting prices or temperatures. For classification, cross-entropy is more common.
